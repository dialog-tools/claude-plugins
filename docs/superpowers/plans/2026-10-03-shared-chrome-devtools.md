# Shared Chrome DevTools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the shared-Chrome DevTools setup in the `dialog-workflow` plugin so every Dialog teammate's Mac, in Claude Code and Codex, runs one shared Chrome on 127.0.0.1:9222, the newest `chrome-devtools-mcp`, orphan cleanup, and the upstream skills with our overlay.

**Architecture:** One zsh launcher (`bin/chrome-devtools-mcp-shared`) is the plugin's only MCP entry point. It reaps orphaned servers, keeps a versioned install of `chrome-devtools-mcp` current, starts the shared Chrome through LaunchServices if needed, and execs the server with `--browserUrl`. One `.mcp.json` works in both clients via `sh -c 'exec "${CLAUDE_PLUGIN_ROOT:-.}/bin/…"'` plus `"cwd": "."`. A sync script imports the upstream skills from npm and re-applies the overlay.

**Tech Stack:** zsh (macOS `/bin/zsh`), Node 22 (`node:test`, ESM scripts), npm, GitHub Actions (`macos-latest`).

**Spec:** `docs/superpowers/specs/2026-10-03-shared-chrome-devtools-design.md`

## Global Constraints

- macOS only. The launcher's shebang is `#!/bin/zsh -f` (skip startup files, which could print to stdout and corrupt MCP stdio).
- The launcher writes nothing to stdout except in `--check` / `--select-orphans` modes and via the exec'd server. All logging goes to stderr, prefixed `chrome-devtools-mcp-shared: `.
- Runtime dependencies: `node`/`npm`, `curl`, `open`, `ps`, `awk`, `find` only.
- State directory: `~/.cache/dialog-chrome-devtools/` (`versions/<v>/`, `current`, `profile/`, `chrome.log`, `.update.lock`, `.chrome.lock`, `.last-update-check`, `.last-reap`).
- Port `9222`, browser URL `http://127.0.0.1:9222`.
- Test-only environment overrides: `DIALOG_CDP_STATE_DIR`, `DIALOG_CDP_PORT`, `DIALOG_CDP_CHROME_APP`.
- MCP server name `chrome-devtools`; Claude tool prefix `mcp__plugin_dialog-workflow_chrome-devtools__`.
- Plugin version `0.4.0`.
- Imported skills: `a11y-debugging`, `chrome-devtools`, `chrome-devtools-cli`, `cookie-debugging`, `debug-optimize-lcp`, `memory-leak-debugging`, `troubleshooting`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Ask Chris before creating or switching branches, pushing, or opening PRs. Work in `claude-plugins` happens on `feat/shared-chrome-devtools` (already created).

- [ ] **Step 3: Write the launcher skeleton with orphan selection**

`plugins/dialog-workflow/bin/chrome-devtools-mcp-shared`:

```zsh
#!/bin/zsh -f
# chrome-devtools-mcp-shared: MCP entry point for chrome-devtools-mcp, used by Claude Code and
# Codex through this plugin's .mcp.json. Every session's server attaches to one shared Chrome
# per machine instead of launching its own, so agents in concurrent sessions don't fight over a
# profile and exited sessions don't leave browsers behind.
#
# On each start:
#   1. reaps chrome-devtools-mcp servers orphaned by exited sessions (at most once a minute)
#   2. keeps chrome-devtools-mcp on the newest npm release (checked at most once a day)
#   3. starts the shared Chrome on 127.0.0.1:$port if nothing answers there
#   4. execs the server with --browserUrl
#
# Modes:
#   --check           run 2 and 3, print a status report, exit instead of exec'ing
#   --select-orphans  read `ps -axo pid=,ppid=,command=` on stdin, print the PIDs step 1 kills
#
# State, shared by Claude Code and Codex: ~/.cache/dialog-chrome-devtools/
# Test-only overrides: DIALOG_CDP_STATE_DIR, DIALOG_CDP_PORT, DIALOG_CDP_CHROME_APP

emulate zsh

state=${DIALOG_CDP_STATE_DIR:-$HOME/.cache/dialog-chrome-devtools}
port=${DIALOG_CDP_PORT:-9222}
browser_url=http://127.0.0.1:$port
versions=$state/versions
keep_versions=3

log() { print -r -- "chrome-devtools-mcp-shared: $*" >&2 }

# ---- 1. orphan reaping -------------------------------------------------------

# An orphan is a chrome-devtools-mcp server process (npm/node/this launcher, never a macOS app
# binary) whose parent is launchd (ppid 1) because its session exited; its whole tree goes with
# it. Also a Chrome on the legacy default profile, left behind when a self-launching server died.
# Never matched: the shared Chrome or any hand-started Chrome, even when its profile lives under
# ~/.cache/chrome-devtools-mcp/.
select_orphans() {
  awk -v self=$$ '
    {
      pid[NR] = $1; ppid[NR] = $2
      cmd = $0; sub(/^ *[0-9]+ +[0-9]+ +/, "", cmd)
      if ($2 != 1 || $1 == self) next
      if (cmd ~ /\.app\/Contents\/MacOS\//) {
        if (cmd ~ /--allow-pre-commit-input/ && cmd ~ /\.cache\/chrome-devtools-mcp\/chrome-profile(-[a-z]+)?( |$)/) doomed[$1] = 1
        next
      }
      if (cmd ~ /chrome-devtools-mcp/) doomed[$1] = 1
    }
    END {
      do {
        grew = 0
        for (i = 1; i <= NR; i++)
          if (!(pid[i] in doomed) && (ppid[i] in doomed)) { doomed[pid[i]] = 1; grew = 1 }
      } while (grew)
      for (p in doomed) if (p != self) print p
    }' | sort -n
}

# SIGKILL: these servers ignore SIGTERM.
reap_orphans() {
  local stamp=$state/.last-reap
  [[ -n $(find $stamp -mmin -1 2>/dev/null) ]] && return 0
  touch $stamp
  local -a doomed
  doomed=($(ps -axo pid=,ppid=,command= | select_orphans))
  (( ${#doomed} )) || return 0
  log "reaping ${#doomed} orphaned process(es): ${doomed[*]}"
  kill -9 $doomed 2>/dev/null
  return 0
}

# ---- main --------------------------------------------------------------------

if [[ $1 == --select-orphans ]]; then select_orphans; exit 0; fi
log "not implemented yet"
exit 1
```

```js
import { spawn, spawnSync } from 'node:child_process';
import { chmodSync, mkdirSync, mkdtempSync, readFileSync, utimesSync, writeFileSync, existsSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join, resolve } from 'node:path';

export const PLUGIN_ROOT = resolve(import.meta.dirname, '../../plugins/dialog-workflow');
export const LAUNCHER = join(PLUGIN_ROOT, 'bin/chrome-devtools-mcp-shared');
export const PORT = '9399';
const FAKE_BIN = resolve(import.meta.dirname, '../fixtures/fake-bin');

// A throwaway state dir plus fake npm/open/curl/ps/uname first on PATH: tests never touch the
// network, the real Chrome, or real processes.
export function sandbox({ latest, chromeUp = false, uname = 'Darwin', chromeApp = true, npmSleep = 0 } = {}) {
  const dir = mkdtempSync(join(tmpdir(), 'cdp-shared-'));
  const state = join(dir, 'state');
  const app = join(dir, 'Google Chrome.app');
  if (chromeApp) mkdirSync(app);
  if (latest) writeFileSync(join(dir, 'latest'), `${latest}\n`);
  if (chromeUp) writeFileSync(join(dir, 'chrome-up'), '');
  const env = {
    PATH: `${FAKE_BIN}:${process.env.PATH}`,
    HOME: process.env.HOME,
    FAKE_DIR: dir,
    FAKE_UNAME: uname,
    FAKE_NPM_SLEEP: String(npmSleep),
    DIALOG_CDP_STATE_DIR: state,
    DIALOG_CDP_PORT: PORT,
    DIALOG_CDP_CHROME_APP: app,
  };
  const lines = (name) => (existsSync(join(dir, name)) ? readFileSync(join(dir, name), 'utf8').split('\n').filter(Boolean) : []);
  return {
    dir, state, app, env,
    npmCalls: (verb) => lines('npm.log').filter((l) => l.startsWith(`${verb} `)),
    openCalls: () => lines('open.log'),
    setPsTable: (rows) => writeFileSync(join(dir, 'ps-table'), rows.join('\n') + '\n'),
    // Install a stub server for `version` as if a previous run had installed it.
    preinstall(version, { current = false } = {}) {
      const binDir = join(state, 'versions', version, 'node_modules/.bin');
      mkdirSync(binDir, { recursive: true });
      writeFileSync(join(binDir, 'chrome-devtools-mcp'), `#!/bin/sh\necho "SERVER ${version} ARGS $*"\n`);
      chmodSync(join(binDir, 'chrome-devtools-mcp'), 0o755);
      if (current) writeFileSync(join(state, 'current'), `${version}\n`);
    },
    // Backdate a state file or directory by `minutes`.
    age(name, minutes) {
      const when = new Date(Date.now() - minutes * 60_000);
      utimesSync(join(state, name), when, when);
    },
  };
}

export function runLauncher(sb, args = []) {
  return spawnSync(LAUNCHER, args, { env: sb.env, encoding: 'utf8', timeout: 60_000 });
}

export function runLauncherAsync(sb, args = []) {
  return new Promise((done) => {
    const child = spawn(LAUNCHER, args, { env: sb.env });
    let stdout = '', stderr = '';
    child.stdout.on('data', (d) => (stdout += d));
    child.stderr.on('data', (d) => (stderr += d));
    child.on('exit', (status) => done({ status, stdout, stderr }));
  });
}
```

installed_bin() { print -r -- $versions/$1/node_modules/.bin/chrome-devtools-mcp }

# A lock directory older than $2 minutes was left by a killed process.
clear_stale_lock() {
  [[ -n $(find $1 -maxdepth 0 -mmin +$2 2>/dev/null) ]] && rmdir $1 2>/dev/null
  return 0
}

# Each version gets its own directory (temp dir + rename), so concurrent sessions never write
# the same files and running servers keep theirs.
install_version() {
  local version=$1 tmp=$versions/.tmp-$1-$$
  log "installing chrome-devtools-mcp@$version"
  if npm install --prefix $tmp --no-audit --no-fund --no-save --silent chrome-devtools-mcp@$version >&2 \
      && [[ -x $tmp/node_modules/.bin/chrome-devtools-mcp ]]; then
    rm -rf $versions/$version
    mv $tmp $versions/$version
  else
    rm -rf $tmp
    log "installing chrome-devtools-mcp@$version failed"
    return 1
  fi
}

set_current() { print -r -- $1 > $state/current.$$ && mv -f $state/current.$$ $state/current }

prune_versions() {
  local -a all
  all=(${(f)"$(ls -1 $versions | sort -t. -k1,1n -k2,2n -k3,3n)"})
  (( ${#all} > keep_versions )) || return 0
  local v
  for v in ${all[1,-$((keep_versions + 1))]}; do rm -rf $versions/$v; done
}

maybe_update() {
  local stamp=$state/.last-update-check lock=$state/.update.lock latest
  [[ -n $(find $stamp -mtime -1 2>/dev/null) ]] && return 0
  clear_stale_lock $lock 10
  mkdir $lock 2>/dev/null || return 0   # another session is updating
  {
    latest=$(npm view chrome-devtools-mcp@latest version 2>/dev/null)
    if [[ -n $latest ]] && { [[ -x $(installed_bin $latest) ]] || install_version $latest }; then
      set_current $latest
      touch $stamp
      prune_versions
    fi
  } always {
    rmdir $lock 2>/dev/null
  }
}

# Prints the version to run; waits (up to 2 min) for another session's first install.
resolve_current() {
  local current i
  for i in {1..120}; do
    current=$(cat $state/current 2>/dev/null)
    [[ -n $current && -x $(installed_bin $current) ]] && { print -r -- $current; return 0 }
    [[ -d $state/.update.lock ]] || break
    sleep 1
  done
  log "no chrome-devtools-mcp installed; check network/npm, then rm $state/.last-update-check and retry"
  return 1
}

# ---- 3. the shared Chrome ----------------------------------------------------

find_chrome_app() {
  local -a candidates
  local app
  if [[ -n $DIALOG_CDP_CHROME_APP ]]; then
    candidates=($DIALOG_CDP_CHROME_APP)
  else
    candidates=("/Applications/Google Chrome.app" "$HOME/Applications/Google Chrome.app")
  fi
  for app in $candidates; do
    [[ -d $app ]] && { print -r -- $app; return 0 }
  done
  return 1
}

chrome_up() { curl -fsS --max-time 1 $browser_url/json/version >/dev/null 2>&1 }

# Started through LaunchServices so Chrome is parented to launchd, not to this session, and
# outlives it.
ensure_chrome() {
  chrome_up && return 0
  local app lock=$state/.chrome.lock held=0 i
  app=$(find_chrome_app) || { log "Google Chrome not found in /Applications or ~/Applications"; return 1 }
  clear_stale_lock $lock 2
  if mkdir $lock 2>/dev/null; then
    held=1
    if ! chrome_up; then
      log "starting shared Chrome on $browser_url"
      mkdir -p $state/profile
      open -g -n -a $app --stdout $state/chrome.log --stderr $state/chrome.log --args \
        --remote-debugging-port=$port --remote-debugging-address=127.0.0.1 \
        --user-data-dir=$state/profile --no-first-run --no-default-browser-check \
        --disable-background-timer-throttling --disable-backgrounding-occluded-windows \
        --disable-renderer-backgrounding about:blank
    fi
  fi
  for i in {1..40}; do
    chrome_up && break
    sleep 0.5
  done
  (( held )) && rmdir $lock 2>/dev/null
  chrome_up || { log "shared Chrome did not answer on $browser_url; see $state/chrome.log"; return 1 }
}

report() {
  local app browser
  app=$(find_chrome_app)
  browser=$(curl -fsS --max-time 1 $browser_url/json/version 2>/dev/null | sed -n 's/.*"Browser": *"\([^"]*\)".*/\1/p')
  print -r -- "chrome-app: ${app:-not found}"
  if [[ -n $browser ]]; then
    print -r -- "endpoint: $browser_url up ($browser)"
  else
    print -r -- "endpoint: $browser_url down"
  fi
  print -r -- "server: chrome-devtools-mcp $1"
  print -r -- "state: $state"
}

# ---- main --------------------------------------------------------------------

if [[ $1 == --select-orphans ]]; then select_orphans; exit 0; fi
if [[ $(uname -s) != Darwin ]]; then log "macOS only (this is $(uname -s))"; exit 1; fi

#!/usr/bin/env node
/**
 * Import the Chrome DevTools skills shipped in the chrome-devtools-mcp npm package into
 * dialog-workflow, then re-apply our shared-browser overlay. Re-run after upstream releases:
 *
 *   node scripts/sync-chrome-devtools-skills.mjs [version]   # default: latest
 *
 * Fails before touching the plugin if an overlay anchor is missing, so an upstream rewrite
 * can't silently drop the overlay.
 */
import { execFileSync } from 'node:child_process';
import { cpSync, existsSync, mkdtempSync, readdirSync, readFileSync, rmSync, writeFileSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join, resolve } from 'node:path';
import { pathToFileURL } from 'node:url';

export const SKILLS = [
  'a11y-debugging',
  'chrome-devtools',
  'chrome-devtools-cli',
  'cookie-debugging',
  'debug-optimize-lcp',
  'memory-leak-debugging',
  'troubleshooting',
];

const LIFECYCLE = `**Browser lifecycle**: In this setup the MCP server never launches its own Chrome. The dialog-workflow plugin's launcher (\`bin/chrome-devtools-mcp-shared\`) attaches every session's server, in Claude Code and Codex, to one shared Chrome on \`http://127.0.0.1:9222\`, starting it if needed. Other agents are using the same browser at the same time.

**Shared browser etiquette**:

- Start with \`new_page\` and pass \`isolatedContext\` set to a name unique to your session (e.g. the worktree or task name). That gives you your own cookies and storage, so logins don't leak between agents. Reuse the same context name for all your pages.
- Only act on \`pageId\`s you created. \`list_pages\` shows every agent's tabs, and page IDs are numbered per server, so never navigate, close, or interact with a page you didn't open, and don't rely on the \`[selected]\` page.
- Avoid browser-wide side effects on pages you don't own (emulation, throttling, dialogs).
- Close your pages with \`close_page\` when you're done.`;

const STEP0 = `### Step 0: Check the shared Chrome

In this setup the server comes from the dialog-workflow plugin and attaches to one shared Chrome on \`http://127.0.0.1:9222\`. Most failures mean that Chrome is down:

1. \`curl -s http://127.0.0.1:9222/json/version\` should return JSON.
2. Run the launcher's self-check: \`bin/chrome-devtools-mcp-shared --check\` inside the installed plugin (\`~/.claude/plugins/cache/dialog-tools/dialog-workflow/<version>/\` for Claude Code, \`~/.codex/plugins/cache/dialog-tools/dialog-workflow/<version>/\` for Codex). It starts Chrome if needed and reports the Chrome app, endpoint and server version. Chrome's log is \`~/.cache/dialog-chrome-devtools/chrome.log\`.
3. Reconnecting the MCP server (\`/mcp\` in Claude Code) also starts Chrome again.
4. Do not "fix" it by switching to a self-launching or \`--isolated\` server: that brings back the per-session Chrome and the orphaned-process leak this setup exists to avoid.

`;

export function applyOverlay(skillFile, text) {
  if (skillFile === 'chrome-devtools/SKILL.md') {
    const anchor = /^\*\*Browser lifecycle\*\*:.*$/m;
    if (!anchor.test(text)) throw new Error(`${skillFile}: "**Browser lifecycle**:" paragraph not found`);
    return text.replace(anchor, () => LIFECYCLE);
  }
  if (skillFile === 'troubleshooting/SKILL.md') {
    const match = /^### Step 1\b/m.exec(text);
    if (!match) throw new Error(`${skillFile}: "### Step 1" heading not found`);
    return text.slice(0, match.index) + STEP0 + text.slice(match.index);
  }
  return text;
}

function main(version = 'latest') {
  const dest = resolve(import.meta.dirname, '../plugins/dialog-workflow/skills');
  const work = mkdtempSync(join(tmpdir(), 'cdm-skills-'));
  try {
    const tgz = execFileSync('npm', ['pack', `chrome-devtools-mcp@${version}`, '--silent', '--pack-destination', work], { encoding: 'utf8' })
      .trim().split('\n').pop();
    execFileSync('tar', ['xzf', join(work, tgz), '-C', work]);
    const pkg = join(work, 'package');
    const resolved = JSON.parse(readFileSync(join(pkg, 'package.json'), 'utf8')).version;

    for (const skill of SKILLS) {
      if (!existsSync(join(pkg, 'skills', skill))) throw new Error(`chrome-devtools-mcp@${resolved} has no skills/${skill}`);
    }
    for (const file of ['chrome-devtools/SKILL.md', 'troubleshooting/SKILL.md']) {
      const path = join(pkg, 'skills', file);
      writeFileSync(path, applyOverlay(file, readFileSync(path, 'utf8')));
    }
    for (const skill of SKILLS) {
      rmSync(join(dest, skill), { recursive: true, force: true });
      cpSync(join(pkg, 'skills', skill), join(dest, skill), { recursive: true });
    }

    const extra = readdirSync(join(pkg, 'skills')).filter((s) => !SKILLS.includes(s));
    if (extra.length) console.warn(`upstream has skills not imported (add to SKILLS?): ${extra.join(', ')}`);
    console.log(`synced ${SKILLS.length} skills from chrome-devtools-mcp@${resolved}`);
  } finally {
    rmSync(work, { recursive: true, force: true });
  }
}

if (import.meta.url === pathToFileURL(process.argv[1]).href) main(process.argv[2]);

`scripts/smoke-chrome-devtools.mjs`:

```js
#!/usr/bin/env node
/**
 * Real-tool smoke test for the shared Chrome DevTools launcher (macOS, manual — not CI). Uses
 * real npm and real Chrome on a spare port with a throwaway state dir, so it never touches the
 * machine's shared Chrome on 9222:
 *   1. three concurrent cold `--check` runs -> one install, one Chrome, parented to launchd
 *   2. two MCP servers share that Chrome, each in its own isolatedContext
 * Then it quits that Chrome and deletes the state dir.
 *
 *   node scripts/smoke-chrome-devtools.mjs [port]   # default 9339
 */
import assert from 'node:assert/strict';
import { execFileSync, spawn } from 'node:child_process';
import { mkdtempSync, rmSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join, resolve } from 'node:path';

const launcher = resolve(import.meta.dirname, '../plugins/dialog-workflow/bin/chrome-devtools-mcp-shared');
const port = process.argv[2] ?? '9339';
const state = mkdtempSync(join(tmpdir(), 'cdp-smoke-'));
const env = { ...process.env, DIALOG_CDP_STATE_DIR: state, DIALOG_CDP_PORT: port };

function run(args) {
  return new Promise((done) => {
    const child = spawn(launcher, args, { env });
    let out = '', err = '';
    child.stdout.on('data', (d) => (out += d));
    child.stderr.on('data', (d) => (err += d));
    child.on('exit', (code) => done({ code, out, err }));
  });
}

function sharedChrome() {
  return execFileSync('ps', ['-axo', 'pid=,ppid=,command='], { encoding: 'utf8' })
    .split('\n')
    .map((l) => l.trim().match(/^(\d+)\s+(\d+)\s+(.*)$/))
    .filter((m) => m && m[3].includes('.app/Contents/MacOS/Google Chrome ') && m[3].includes(`--user-data-dir=${state}/profile`))
    .map((m) => ({ pid: Number(m[1]), ppid: Number(m[2]) }));
}

function mcpServer(name) {
  const proc = spawn(launcher, [], { env, stdio: ['pipe', 'pipe', 'inherit'] });
  let buf = '', nextId = 1;
  const pending = new Map();
  proc.stdout.on('data', (chunk) => {
    buf += chunk;
    let i;
    while ((i = buf.indexOf('\n')) >= 0) {
      const line = buf.slice(0, i).trim();
      buf = buf.slice(i + 1);
      if (!line) continue;
      const msg = JSON.parse(line);
      if (msg.id && pending.has(msg.id)) { pending.get(msg.id)(msg); pending.delete(msg.id); }
    }
  });
  const send = (method, params) => new Promise((done) => {
    const id = nextId++;
    pending.set(id, done);
    proc.stdin.write(JSON.stringify({ jsonrpc: '2.0', id, method, params }) + '\n');
  });
  return {
    proc,
    async init() {
      await send('initialize', { protocolVersion: '2025-06-18', capabilities: {}, clientInfo: { name, version: '0' } });
      proc.stdin.write(JSON.stringify({ jsonrpc: '2.0', method: 'notifications/initialized' }) + '\n');
    },
    async call(tool, args) {
      const res = await send('tools/call', { name: tool, arguments: args });
      assert.ok(!res.error && !res.result.isError, `${name} ${tool}: ${JSON.stringify(res.error ?? res.result)}`);
      return res.result.content.map((c) => c.text ?? '').join('\n');
    },
  };
}

const selectedPage = (text) => Number(text.match(/^(\d+):.*\[selected\]/m)[1]);

try {
  const checks = await Promise.all([1, 2, 3].map(() => run(['--check'])));
  for (const c of checks) assert.equal(c.code, 0, c.err);
  const installs = checks.map((c) => c.err).join('').match(/installing chrome-devtools-mcp@/g) ?? [];
  assert.equal(installs.length, 1, 'expected exactly one install');
  const chromes = sharedChrome();
  assert.equal(chromes.length, 1, 'expected exactly one shared Chrome');
  assert.equal(chromes[0].ppid, 1, 'shared Chrome should be parented to launchd');
  console.log('ok: 3 concurrent cold starts -> 1 install, 1 Chrome parented to launchd');
  console.log(checks[0].out.trim());

  const a = mcpServer('agent-a'), b = mcpServer('agent-b');
  try {
    await Promise.all([a.init(), b.init()]);
    const [pa, pb] = await Promise.all([
      a.call('new_page', { url: 'data:text/html,<title>A</title>', isolatedContext: 'agent-a' }),
      b.call('new_page', { url: 'data:text/html,<title>B</title>', isolatedContext: 'agent-b' }),
    ]);
    const [ta, tb] = await Promise.all([
      a.call('evaluate_script', { pageId: selectedPage(pa), function: '() => document.title' }),
      b.call('evaluate_script', { pageId: selectedPage(pb), function: '() => document.title' }),
    ]);
    assert.match(ta, /"A"/);
    assert.match(tb, /"B"/);
    await Promise.all([a.call('close_page', { pageId: selectedPage(pa) }), b.call('close_page', { pageId: selectedPage(pb) })]);
    console.log('ok: two servers shared one Chrome in separate isolatedContexts');
  } finally {
    a.proc.kill();
    b.proc.kill();
  }
} finally {
  for (const { pid } of sharedChrome()) process.kill(pid, 'SIGTERM');
  rmSync(state, { recursive: true, force: true });
}
```
